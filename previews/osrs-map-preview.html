osrs-cache-service · terrain + map icons

The map, with its icons back on

Terrain rendered from the cache, with the game's own map icons composited on top — banks, altars, shops, guilds, quest markers. Icon positions come from the object locations (/map/icons), the symbols from the sprite archive. Both are live data, drawn over the baked terrain tiles at 8 px per game tile.

Cities · terrain + icons

Four places, fully marked up

Each is a cluster of map squares stitched together, with every map icon in view placed where its object stands.

4,043 map icons are placed world-wide. They are kept as data, not baked into the tiles — so the client can toggle, filter, hover and search them, and restyling them never re-bakes a pixel. The ~5M individual objects (walls, doors, scenery) are queryable the same way via /map/locations.
