FRZ-1 steps 2, 4 and 5. The rows, kill rates, prices and item images are live OSRSClans data from 25 Nov 2026. The frenzy points, the hover texts and the note lines are mock. Today's row of each set sits at the bottom.

Round 2: Foundry kill rates on the reference page (step 4)

Where staff set a kill rate for a source that OSRSClans gives none. The API is built: PUT and DELETE /reference/kill-rates/{source} need frenzy edit, and the loot rate routes serve the rate marked Foundry. The Hallowed Sepulchre sources are live and have no OSRSClans rate. The Grand Hallowed Coffin rate of 6 an hour and Hammer Time as the staff member who set it are mock. Each candidate also moves the page onto the OSRSClans routes (step 5).

K1 Rate in the table

Each source row carries its kill rate. A source with no rate shows No rate and a Set button. A Foundry rate shows a pencil.

K1, Set open

Set opens a popover beside the cell, so the row keeps its size.

K2 Rate in the source dialog

The table only reads. A source opens its dialog, which holds the kill rate above the drop table, grouped by the Wiki heading.

K3 Kill rates tab

A tab of its own lists the sources with no OSRSClans rate, each with a rate field, who set it, Save and Remove.

Frenzy item editor (step 2)

Three frenzy source cards: Draconic visage from Vorkath, Twisted bow from the Chambers of Xeric at a deathless trio's 65,000 points, and Ring of endurance from the Grand Hallowed Coffin, which has no kill rate.

E1 Rate line

Each item shows the source row it takes its rate from. Change opens a dialog of all sources for the item, fastest first. The fields stay editable.

E1, Change open

The dialog for Draconic visage. Use takes that source's chance and kill rate.

E2 Rate select

A Rate source dropdown on each item. The figures read from the picked row. By hand turns them back into fields.

E2, dropdown open

The dropdown lists all sources for the item, fastest first.

E3 From the card

The rate comes from the card's own source. No control per item. The pencil sets a rate by hand.

Reference page (step 5)

The staff Reference Data page on /reference/loot-rates/sources and /reference/loot-rates?source=. Vorkath is the open source. The page description is today's line, which names the OSRS Wiki. Its new line is yours to write.

R1 Tabs and a dialog

Today's shape with the OSRSClans categories as tabs, a search, and kill rates on each source. A source opens its drop table in a dialog.

R1, Vorkath open

The drop table, grouped by the Wiki's own headings, with item images and hours a drop.

R2 List and detail

A source list with a category dropdown on the left, the picked source's drop table on the right. Under 1024 px the table follows the list.

R3 Item search first

One search over items and sources answers with loot rate rows, fastest first. The category tabs browse the sources below it.
